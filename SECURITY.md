# Security and data-integrity reports

This is an experimental filesystem beta with no independent security audit. Treat untrusted filesystem images and physical write access as sensitive.

Use GitHub's private vulnerability reporting on this repository for exploitable issues. For reproducible non-sensitive defects, open a public issue with a synthetic image reproducer and redacted logs. Never post real recovery journals, file contents, passwords or device identifiers.

Preserve failed recovery state. Do not delete an owner or journal to work around a refusal. No response-time or data-recovery guarantee is provided.
